# SportDent Step8 多変量解析

Step7の重要因子ランキング上位5因子を対象に、歯牙障害とそれ以外の登録事例の調整後関連をロジスティック回帰で探索します。同じ7,682件を使うため、独立データによる再現確認ではありません。

`Step8_Main.py --force`を実行します。入力はStep7と同じStep2確認済みCSV群と、Step7-48の重要因子ランキングです。Step1〜7の成果物は書き換えません。既存のStep8成果物がある場合、`--force`なしでは停止します。

上位因子には階層関係や構造的な重なりがあるため、以下の3モデルに分けます。

- 主モデル：場合別1、被災学校種、性別、給付年度（西暦換算）
- 詳細活動モデル：場合別2、被災学校種、性別、給付年度（西暦換算）
- 通学中サブグループ：通学方法、発生場所2（二値：道路／道路以外）、被災学校種、性別、給付年度（西暦換算）

和暦と給付年度から西暦相当の給付年度を作り、平成と令和の同じ年数を混同しないようにします。事故発生年とはみなしません。空欄と欠損は「不明・記載なし」とし、30件未満または比較する片方が5件未満のカテゴリは統合します。公開集計の1〜4件セルは、差し引きで戻せないよう二次セルとともに非表示にします。

本解析は登録事例内の関連を示すもので、一般集団の発生リスクや因果関係を示しません。
