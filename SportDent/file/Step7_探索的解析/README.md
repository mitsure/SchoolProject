# SportDent Step7 探索的解析基盤 v1.1

## 概要

`Step7_Main.py`だけを実行し、`Step7_Sub`内の解析を番号順に一括実行します。

## 入力方針

元データは直接使用しません。Step2で抽出し、目視確認済みのCSV群を使用します。

```text
CreateData/
└── Step2_傷害カテゴリ別解析/
    └── カテゴリ別抽出データ/
        ├── Step2-1_...歯牙障害抽出.csv
        ├── Step2-2_...抽出.csv
        └── ...
```

Mainが次の3種類を作成します。

- 全体：すべてのカテゴリ別CSVを統合
- 歯牙障害：ファイル名に「歯牙障害抽出」を含むCSV
- 歯牙障害以外：それ以外のCSVを統合

各行には入力元確認用として、`Step7_入力元ファイル`と`Step7_入力元カテゴリ`を追加します。
比較用に`Step7_歯牙障害フラグ`（歯牙障害=1、その他=0）も追加します。

Linux環境でのUnicode NFC/NFDの違いはMainが実パスを一意に照合して解決します。
自由記載内の改行・引用符不整合で通常読込の構造検証に失敗した場合は、
年号で始まる事例行を根拠に論理レコードを復元し、その事実を診断CSVとログに残します。

## 実行対象

```python
TARGET_DATASETS = [
    "全体",
    "歯牙障害",
    "歯牙障害以外",
]
```

現在は`ACTIVE_ANALYSIS_MAX = 50`とし、Sub01〜50を実行します。
Sub09〜21の群間比較は、歯牙障害と歯牙障害以外の両群が含まれる「全体」でのみ成立します。
単一群データセットでは「解析不能・スキップ」と記録し、プログラムエラーと区別します。

Sub10〜16ではχ²検定、Fisher正確確率検定、バイアス補正Cramér's V、
調整済み標準化残差、オッズ比、リスク比、95%信頼区間、Benjamini-Hochberg補正を出力します。
期待度数5未満セルが20%を超える場合または期待度数1未満がある場合は、χ²検定の前提条件を「要注意」とします。
時刻列が存在しないため、Sub22は時間帯を推測生成せず解析不能理由を出力します。

Sub23は単語の総出現回数に加え、同一事例内の重複を1回とした事例出現数・出現率を出力します。
Sub24は品詞・品詞細分類の形態素数と事例出現率を出力します。
Sub25は歯牙障害対歯牙障害以外の平均TF-IDF差を出力します。
「前歯」と「歯」は別トークンのまま扱い、任意の統合は行いません。

Sub26は事例単位の共起ペアについて、最低5事例を満たすノード表・エッジ表を作成します。
Sub27は解析対象語の2-gram・3-gramを事例出現数3件以上で出力します。
Sub28とSub32はStep4のJaccard・類似事例成果を使い、重複計算しません。
Sub29 WordCloudは定量比較に不向き、単語頻度表より追加価値が小さいため非採用です。
Sub30は事例別文字数・形態素数・解析対象語数を出力します。
Sub31は単語の事例出現率差、OR、95%CI、Fisher p値、BH補正p値を作成します。
浮動小数点の下限を超えるp値は0とせず最小正数とし、`p値下限丸め`列で明示します。

Sub33はカテゴリ値を`"列名=値"`形式のトランザクションとし、
支持度1%以上の頻出1〜3項目集合をAprioriで抽出します。
欠損値は関連パターンを過度に支配しやすいため、トランザクションから除外します。
Sub34 FP-GrowthはAprioriと同じ結果を別アルゴリズムで再計算するため非採用です。
Sub35はSub成果物に依存せず同じApriori計算を共通キャッシュから取得し、
信頼度20%以上かつlift 1.20以上の関連ルールを出力します。
関連ルールは併存パターンであり、時系列・因果関係を示しません。

Sub36はOne-hotカテゴリ特徴を使い、k=2〜8のMiniBatch K-meansをsilhouette scoreで比較します。
スコアが低い場合は明瞭な自然クラスタと解釈しません。
Sub37は同じOne-hot特徴にPCAを適用し、寄与率、事例スコア、主要負荷量を出力します。
Sub38 t-SNEとSub39 UMAPはパラメータ依存の視覚化であり、軸・距離の定量解釈ができないため非採用です。
Sub40はカテゴリ頻度の負対数による希少性スコアと、文長のMADベース頑健zスコアで確認候補を出力します。
Sub41は5件以下のカテゴリを含む事例と抽出理由を出力し、再識別リスクのある自由記載は含めません。
Sub40・41はどちらも事例を自動除外しません。
Sub42はカテゴリ変数全体と歯牙障害フラグの相互情報量を列別に計算します。
これは探索的関連であり、因果的重要度や調整済み効果を示しません。

Sub43は歯牙障害群の調整済み標準化残差の絶対値上位30をヒートマップにします。
Sub44は関連が強かった場合別2の上位8水準とその他をMosaic plotで比較します。
Sub45 Sankey diagramは、時間的な流れでないカテゴリ間関係を移行・因果と誤読させる可能性があるため非採用です。
Sub46は群内割合差、log2(OR)、件数をBubble chartで表現します。
Sub47は共起数10事例以上のペアから、頻度で標準化した関連強度上位18語のネットワーク図を作成します。
図はPNG 300dpiとSVGで保存し、実在する日本語フォントが見つからない場合は文字化け図を生成せず失敗理由を記録します。
Sub48は補正Cramér's V、相互情報量、最大絶対調整済み標準化残差、最大絶対log2(OR)の
各百分位順位を等ウェイトで統合し、重要因子の探索的優先順位を作成します。
最大絶対log2(OR)は、合計20件以上かつ歯牙障害・非歯牙障害の両群3件以上を満たす
カテゴリだけを対象とし、ゼロセルや極少数セルが順位を過度に支配することを防ぎます。
総合点は因果的重要度や交絡調整済み効果を意味しません。
Sub49は20件以上かつ両群3件以上のカテゴリを対象に、効果量、群内割合差、
BH補正後の統計的確実性、対象規模を統合して研究テーマ候補を順位付けします。
欠損カテゴリはテーマ候補から除外し、推奨上位表では同一因子を最大2候補とします。
Sub50はデータ概要、重要因子、研究テーマ候補、全成果物の所在、解釈上の注意、
論文反映前の確認事項をMarkdown総合レポートへ統合します。
先行成果物が解析不能または未生成の場合は推測せず、その旨を明記します。
また、各データセットの`Report/Step7-01〜50_Result.txt`へSub01〜50を一つに統合し、
主要結果の要約、各Subの「このデータでわかること」と「この結果でわかること」、
解釈上の限界、対応CSVの行列数・列名・先頭10行、
図ファイルの所在、成果物がない場合の確認先を記録します。
全体解析から研究利用価値の高い情報を`CreateData/Step7/FavariteInfo/`へ整理し、
重要知見、論文利用候補、次段階解析計画、研究者確認チェックリストを生成します。
このフォルダでは観測結果とCodexによる研究上の提案を区別して記載します。
一般の読者も閲覧することを想定し、専門用語を避け、必要な用語には本文中で説明を付けます。

## 入力診断の読み方

`CreateData/Step7/Step7_入力ファイル診断.csv`に、ファイル別件数、読込方法、
Step1の既存傷害種別集計との差を出力します。Step1は件数照合のみに使用し、
Step7の解析データ自体はStep2のカテゴリ別CSVのみから作成します。

## 出力先

```text
CreateData/
└── Step7/
    ├── 全体/
    ├── 歯牙障害/
    └── 歯牙障害以外/
```

実行時に`CreateData/Step7`を削除して再生成します。日時付きフォルダは作成せず、古い結果へ追記しません。

## settingsの保存先

各Subでは次を直接使用します。

- `settings["csv_dir"]`
- `settings["figure_dir"]`
- `settings["table_dir"]`
- `settings["report_dir"]`
- `settings["summary_dir"]`

## 重複処理

初期状態では重複を勝手に削除しません。完全一致重複候補をログへ記録します。一意ID列が確定したら`UNIQUE_ID_COLUMN`へ設定できます。

## スキップ処理

データ0件はエラーにせず、ログを残してスキップします。統計解析固有の成立条件は各Subで追加します。

## 実行

```bash
python Step7_Main.py
```
