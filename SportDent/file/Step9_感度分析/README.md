# SportDent Step9 感度分析

Step8の多変量解析が、カテゴリのまとめ方や給付年度（西暦換算）の扱いを変えても大きく変わらないかを確認します。給付年度を事故発生年とはみなしません。

`Step9_Main.py --force`を実行すると、感度分析、交互作用、VIF、5分割交差検証、確認候補、自転車・徒歩二群の感度分析、フォレストプロット、総合レポートを`CreateData/Step9_感度分析/`に作成します。既存成果物がある場合、`--force`なしでは停止します。

`CreateData/Step9_感度分析/Step9-09_なぜこの結果になったのか_解釈レポート.md`では、統計的に確認できる理由と、歯科臨床・行動面から考えられる仮説を分けて記載します。

フォレストプロットはPNGと、文字や線を個別編集できるSVGで出力します。縦軸に比較項目と基準カテゴリ、横軸に調整オッズ比と95%信頼区間を示します。
