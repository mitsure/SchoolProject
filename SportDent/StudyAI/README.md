# SportDent StudyAI

このフォルダは、SportDentのStep4およびStep7〜12を横断し、AIが研究利用の観点から整理した資料です。Jaccard係数の主な根拠はStep4です。Step12は新しい解析ではなく、Step8〜10の確認済み結果を投稿用にまとめた派生成果物として扱います。

## 収録資料

- `01_AI統合解析レポート.md`：研究全体の主要所見とAIによる統合解釈
- `02_AI仮説ランキング.md`：今後検証する研究仮説の優先順位
- `03_AI追加解析ロードマップ.md`：仮説を検証するための具体的な解析計画
- `04_AI解析の限界と利用ルール.md`：AI出力を研究で利用する際の注意事項
- `05_根拠データ対応表.csv`：各所見と元成果物の対応
- `06_歯科医師向け要点.md`：短時間で確認できる要約
- `07_研究発表構成案_Jaccard必須版.md`：Jaccard係数を中心に組み込んだ口演構成
- `08_演題名・抄録案_Jaccard版.md`：データベース名とJaccard係数を明記した演題名・構造化抄録案
- `09_Step8〜12監査と修正記録.md`：今回確認した問題点、修正内容、今後の確認事項
- `10_Step8〜12全結果反映サマリー.md`：修正後の主要数値、採用可否、元成果物をStep別にまとめた最終確認用資料
- `11_最終再監査チェック結果.md`：自動検証の合格結果、修正漏れの確認、次工程に残る人手作業
- `12_Step11コードブック承認案.md`：歯科医師レビュー開始前の臨床定義、統計基準および承認手順の推奨案
- `13_Step11レビュー後半工程.md`：回答原本の凍結、第三者調停、最終人手仕様の凍結および内部ホールドアウト評価の実施順序
- `14_Step11コードブック事前チェック結果.md`：Codexが実施した技術・統計・Excel整合性チェックと、人の確認が必要な残項目
- `14_Step11一人運用ガイド.md`：AI仮分類を研究者1名が確認する場合の入力・検査・利用上の注意
- `15_Step11通学中590件_AI暫定解析.md`：承認済みコードブックを590件へ適用した人手確認前の探索結果
- `16_Step11_AI標本監査計画.md`：AI回答を伏せた別標本100件の一人研究者監査計画
- `17_最終研究発表案_Jaccard・基本項目統合版.md`：確定結果とAI暫定結果を分離した最終口演・統合抄録案

LLMによる入力支援システムは研究解析資料と分離し、`SportDent/StudyLLM`で管理する。

## 重要な位置付け

AIの役割は、集計済み結果の整理、仮説生成、矛盾の検出、追加解析案の提示です。AIの文章は、臨床判断、倫理判断、原文レビュー、先行研究との照合を代替しません。

Step11の旧単一分類は、複数機転の順序を扱えない既知のルール問題があり、単一主受傷機転、直接外力、予防可能性、関連検定および図は使用停止中です。複数ラベル語彙検出は内部の原文検索補助に限定してください。固定コードブック`Step11-CB-1.0.0-rc1`は2026-08-12に役割コードで承認済みです。新しい規則による通学中590件のAI暫定分類は完了しましたが、歯科医師による全件確認前であり、探索的補足に限定します。開発用A/B回答は各0／100件です。別に、AI回答と歯牙障害区分を伏せた一人研究者用の標本監査100件Excelを作成済みで、回答は0／100件です。

Step4のJaccard係数は、主として歯牙障害1,583件の内部で「2特徴が同じ事例に現れた割合」を示すペア単位の探索結果です。特徴が連続した受傷過程を作ること、歯牙障害群に特異的であること、予測性能を高めることは証明していません。Step8・9の多変量解析は定型項目の「通学中」と歯牙障害分類の関連を評価したもので、Jaccardで得た自転車・転倒・顎顔面等のペアや受傷連鎖を検証した解析ではありません。

年に関する項目は、元データの「給付年度」を西暦換算して用いています。事故の発生日そのものを表す「発生年」とは区別します。

このフォルダには事例原文、内部ID、個人を推測できる情報を保存しません。
