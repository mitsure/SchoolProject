# 最終研究発表案：基本項目・自由記述・Jaccard係数の統合

## 推奨演題名

**学校等事故事例検索データベースを用いた歯牙障害事例の構造化項目および自由記述の探索的解析―Jaccard係数による特徴の重なりと登録事例内関連―**

「機械学習入力特徴量候補」を前面に出す場合の演題名は次とする。

**学校等事故事例検索データベースを用いた歯牙障害事例のテキストマイニング―Jaccard係数による機械学習入力特徴量候補の探索―**

現時点では予測モデルへ入力して性能を検証していないため、「特徴量の選定」ではなく「候補の探索」と表現する。

## 発表の中心メッセージ

学校等事故事例検索データベースの基本項目からは、学校種、活動場面、通学方法、発生場所などの登録状況を比較できる。自由記述を解析すると、転倒、乗り物、顎顔面、歯牙などの記載上の重なりを追加して把握できる。両者は同じ情報ではなく、基本項目が事故の枠組み、自由記述が事故経過の詳細を補う。

Jaccard係数は自由記述から作成した2特徴が同じ事例にどの程度現れるかを示すが、原因、時間順序、予測寄与は示さない。

## 10分口演の構成

### 1．背景

- 学校事故データベースには基本項目と事故状況の自由記述がある。
- 基本項目だけでは、接触対象や転倒後の経過を十分に表せない。
- 自由記述の特徴を頻度だけでなく、特徴同士の重なりでも評価するためJaccard係数を用いた。

### 2．目的

1. 歯牙障害事例の基本項目を整理する。
2. 自由記述から頻出語、特徴語、2語の組合せを抽出する。
3. Jaccard係数により歯牙障害事例内の特徴ペアの重なりを評価する。
4. 基本項目と自由記述から得られる情報を分けて整理し、機械学習入力候補を探索する。

### 3．対象

- 登録された長期障害事例：7,682件
- 歯牙障害：1,583件
- 歯牙障害以外：6,099件
- 給付年度（西暦換算）：2005～2023年度相当

歯牙障害以外群は健常者ではなく、別の長期障害として登録された事例群である。

### 4．基本項目から得られた情報

- 通学中590件中、歯牙障害262件（44.4%）
- 自転車356件中、歯牙障害218件（61.2%）
- 徒歩202件中、歯牙障害43件（21.3%）
- 登校中47.0%、下校中42.3%

これらは登録障害事例内の構成割合であり、全通学者における事故発生率ではない。

### 5．多変量解析

- 通学中 対 課外指導：調整オッズ比3.05（95%CI 2.51–3.71）
- 小学校 対 高校：0.33（0.27–0.40）
- 中学校 対 高校：0.50（0.44–0.58）
- 探索的通学中サブグループの徒歩 対 自転車：0.35（0.18–0.69）

「通学によりリスクが3.05倍」とは説明せず、登録事例内で歯牙障害に分類されるオッズの比較とする。

### 6．自由記述の頻度・TF-IDF・2-gram

頻度解析では前歯721件、顔面489件、転倒398件、自転車216件などが認められた。2-gramでは当たる―前歯103件、転倒―顔面92件、顔面―強打87件、自転車―登校70件などが抽出された。

TF-IDFでは前歯、歯、口、顔面、自転車、折れる、転倒、強打等が歯牙障害群で高値を示した。ただし、前歯、破折、補綴等は結果・治療に近く、歯牙障害予測の入力からは除外候補とする。

### 7．Jaccard係数

**J(A,B)＝両特徴を含む事例数÷少なくとも一方を含む事例数**

| 特徴ペア | Jaccard係数 | 共通事例数 |
|---|---:|---:|
| 登校―自転車 | 0.330 | 76 |
| 自転車―転倒 | 0.329 | 152 |
| 転倒―顎顔面 | 0.289 | 242 |
| 乗り物―転倒 | 0.287 | 165 |
| 転倒―歯牙 | 0.233 | 237 |
| スポーツ用具―歯牙 | 0.226 | 235 |
| 転倒―床 | 0.208 | 120 |

これらはそれぞれ別のペアであり、「自転車→転倒→顔面→歯牙」という一本の順序を証明しない。

### 8．基本項目と自由記述の違い

| 基本項目 | 自由記述から追加できる情報 |
|---|---|
| 通学中、登下校 | 転倒・衝突・転落などの事故経過 |
| 通学方法 | 乗り物部品、路面、構造物などの接触対象 |
| 発生場所 | 濡れた路面、段差、操作、速度などの具体的状況 |
| 学校種、性別、給付年度 | 顔面への直接外力、部位記載、複数機転の順序 |

自由記述は基本項目を置き換えるのではなく、詳細を補う。ただし、原文に書かれていない場合は自動的に欠落する。

### 9．通学中590件のAI暫定分類

- 転倒・つまずき326件
- 衝突・接触141件
- 転落・落下51件
- 判定不能72件
- AI暫定分類上の歯牙障害割合：転倒53.4%、衝突36.9%、転落35.3%

このスライドは補足扱いとし、「歯科医師による全件確認前」と明記する。標本監査が未完了なら抄録の主要結果へは入れない。

### 10．結論

1. 基本項目では、登録事例内で通学中と歯牙障害分類との関連が認められた。
2. 自由記述では、自転車―転倒、転倒―顎顔面、転倒―歯牙等の特徴ペアをJaccard係数で定量化できた。
3. Jaccard係数は特徴の重なりと冗長性の整理に有用だが、原因、順序、予測寄与は示さない。
4. 機械学習へ進む場合は、予測時点を先に定義し、歯牙障害や治療結果を直接表す語を除外する必要がある。
5. AIによる事故経過の構造化は、歯科医師による盲検標本監査後に研究利用の可否を判断する。

## 統合抄録案

### 【目的】

学校等事故事例検索データベースには、学校種、活動場面、発生場所等の構造化項目と事故状況の自由記述が収録されている。本研究では、歯牙障害と構造化項目との関連を検討するとともに、歯牙障害事例の自由記述にテキストマイニングを行い、Jaccard係数を用いて特徴の重なりを評価することを目的とした。さらに、構造化項目と自由記述から得られる情報を分けて整理し、機械学習に利用する入力特徴量候補を探索した。

### 【方法】

学校等事故事例検索データベースに登録された長期障害事例7,682件（給付年度を西暦換算して2005～2023年度相当）を対象とした後ろ向き観察研究とした。歯牙障害1,583件と歯牙障害以外6,099件を比較し、歯牙障害の有無を目的変数として、活動場面、学校種、性別および給付年度（西暦換算）を説明変数とする探索的多変量ロジスティック回帰を行った。歯牙障害事例の自由記述はPythonおよびJanomeを用いて形態素解析し、事例出現頻度、歯牙障害以外群との平均TF-IDF差、および解析用語列における2-gramを求めた。さらに、歯牙障害群内で2特徴の共通事例数を和集合事例数で除したJaccard係数を算出した。頻度、平均TF-IDF差、2-gramおよびJaccard係数を探索的に照合し、予測時点で利用できる情報を入力候補、受傷結果や治療を直接示す情報を除外候補として整理した。

### 【結果】

構造化項目の多変量解析では、学校種、性別および給付年度（西暦換算）を同時に考慮した場合、通学中は課外指導に対し、登録事例が歯牙障害に分類される調整オッズ比が3.05（95%CI 2.51–3.71）であった。歯牙障害1,583件内の頻度解析では、前歯721件（45.5%）、顔面489件（30.9%）、転倒398件（25.1%）、自転車216件（13.6%）に記載が認められた。歯牙障害群では、前歯、歯、口、顔面、自転車、転倒等の平均TF-IDFが歯牙障害以外群より高かった。2-gramでは当たる―前歯103件、転倒―顔面92件、顔面―強打87件、自転車―登校70件であった。

Jaccard係数を用いた結果、原文語と対応する辞書カテゴリでは、前歯―歯牙0.966（共通721件）、自転車―乗り物0.931（216件）、顔面―顎顔面0.853（489件）、転倒語―転倒カテゴリ0.785（398件）と高い重なりを認めた。これらは同じ内容を重複して表す特徴であるため、機械学習入力時には両方をそのまま採用せず、代表特徴への統合候補とした。一方、事故状況を表す異なる特徴間では、登校―自転車0.330（76件）、自転車―転倒0.329（152件）、転倒―顎顔面0.289（242件）、乗り物―転倒0.287（165件）、転倒―歯牙0.233（237件）、スポーツ用具―歯牙0.226（235件）であった。この結果から、自転車・乗り物、転倒、スポーツ用具等を事故発生状況の入力候補とし、顎顔面、歯牙等は事故類型や受傷部位を分類する場合の候補として目的別に整理した。ただし、歯牙、前歯、破折等は歯牙障害の結果を直接示すため、歯牙障害予測では除外候補とした。

### 【考察】

構造化項目は登録事例内の群間関連を示し、自由記述は受傷機転、原因物、部位等の詳細を補った。Jaccard係数により特徴ペアの重なりを定量化できたが、各ペアは別々の結果であり、因果関係、時間的順序、歯牙障害群への特異性または予測寄与を示すものではない。本研究は登録された長期障害事例内の比較であり、一般の児童生徒における歯牙障害の発生率や因果的リスクを示さない。機械学習への応用では、目的変数と予測時点を事前に定め、前歯、歯牙、破折、補綴等の結果情報を入力から除外し、特徴選択にも使用していないデータで性能を評価する必要がある。
