## 推奨演題名

**学校等事故事例検索データベースを用いた歯牙障害事例のテキストマイニング―Jaccard係数による機械学習入力特徴量候補の探索―**

現段階では、候補を採用した最終モデルや未使用データでの予測性能を示していない。「選定」ではなく「候補の探索」と表現する。

## この研究で行ったこと

### 1．歯牙障害事例の抽出と形態素解析

学校等事故事例検索データベースから、歯牙障害に分類された1,583件を抽出した。事故発生状況の自由記述をPythonで処理し、Janomeを用いて文章を単語に分け、主に名詞・動詞・形容詞を解析対象とした。

形態素解析とは、文章を意味のある最小単位に分け、それぞれの品詞を判定する処理である。

### 2．頻度解析

各単語について、文章中の総出現回数と、その単語を含む事例数を集計した。単に同じ文章内で繰り返された語を評価するのではなく、歯牙障害1,583件のうち何件に出現したかという「事例出現率」も算出した。

実際の主な結果は次のとおりであった。

| 単語 | 総出現回数 | 出現事例数 | 事例出現率 |
|---|---:|---:|---:|
| 前歯 | 764 | 721 | 45.5% |
| 顔面 | 501 | 489 | 30.9% |
| 練習 | 507 | 462 | 29.2% |
| 歯 | 489 | 444 | 28.0% |
| 当たる | 427 | 410 | 25.9% |
| ボール | 506 | 402 | 25.4% |
| 転倒 | 409 | 398 | 25.1% |
| 強打 | 303 | 302 | 19.1% |
| 自転車 | 293 | 216 | 13.6% |
| 野球 | 209 | 205 | 13.0% |

「部」「本」「れる」など、単独では事故状況を解釈しにくい語も上位に含まれた。このため、出現頻度だけで入力特徴量を決定せず、後続の解析結果と照合した。

### 3．TF-IDF解析

TF-IDFは、ある群で比較的よく使われ、別の群ではあまり使われない語を見つける方法である。本解析では歯牙障害群と歯牙障害以外群の平均TF-IDFを比較した。

歯牙障害群で値が高かった主な語は「前歯」「歯」「口」「顔面」「自転車」「折れる」「転倒」「強打」「床」「野球」「ボール」「当たる」であった。一方、「補綴」「歯科」などの治療・転帰を示す語も高かったため、事故発生前または事故発生時の予測に使う入力特徴量からは除外候補とした。

### 4．2-gram解析

2-gram解析では、形態素解析後に対象品詞の抽出等を行った**解析用の語列**で隣接する2語の組合せを集計した。原文の文字列上で直接隣接する2語とは限らない。単語単独よりも具体的な事故状況を把握することを目的とした。

事故状況または受傷機転を表す主な組合せは次のとおりであった。

| 2語の組合せ | 出現事例数 | 事例出現率 |
|---|---:|---:|
| 野球―部 | 174 | 11.0% |
| 部―練習 | 145 | 9.2% |
| バランス―崩す | 114 | 7.2% |
| 当たる―前歯 | 103 | 6.5% |
| 口―当たる | 102 | 6.4% |
| 練習―試合 | 97 | 6.1% |
| 転倒―顔面 | 92 | 5.8% |
| 顔面―強打 | 87 | 5.5% |
| 自転車―登校 | 70 | 4.4% |
| 自転車―下校 | 62 | 3.9% |
| 転倒―前歯 | 52 | 3.3% |
| 前歯―折れる | 42 | 2.7% |

「歯科―補綴」「補綴―加える」などの治療内容や結果記載も高頻度であったが、事故原因を表す入力特徴量とは区別した。

### 5．Jaccard係数による特徴の重なりの評価

Jaccard係数を用いて、歯牙障害1,583件の内部で、2つの特徴が同じ事例にどの程度重なって出現するかを評価した。

**Jaccard係数＝両方の特徴を含む事例数÷少なくとも一方を含む事例数**

事故状況の解釈に利用できる主な組合せは次のとおりであった。

| 特徴の組合せ | Jaccard係数 | 共通事例数 | 読み取れる内容 |
|---|---:|---:|---|
| 登校―自転車 | 0.330 | 76 | 自転車登校場面の重なり |
| 自転車―転倒 | 0.329 | 152 | 自転車と転倒の重なり |
| 転倒―顎顔面 | 0.289 | 242 | 転倒と顎顔面受傷の重なり |
| 乗り物―転倒 | 0.287 | 165 | 乗り物と転倒の重なり |
| 転倒―歯牙 | 0.233 | 237 | 転倒と歯牙受傷の重なり |
| スポーツ用具―歯牙 | 0.226 | 235 | スポーツ用具と歯牙受傷の重なり |
| 転倒―床 | 0.208 | 120 | 転倒と床特徴の重なり（順序不明） |

Jaccard係数はペア単位の共起であり、因果関係、事故の時間的順序、3項目以上が同じ事例で一本の連鎖を作ること、歯牙障害群への特異性、機械学習の予測性能への寄与を示さない。また、「前歯―歯牙」0.966、「自転車―乗り物」0.931のような非常に高い値は、原文の単語と、その単語を用いて作成した辞書カテゴリとの対応を主に反映する。この種の組合せは、新しい臨床所見や辞書の外的妥当性ではなく、分類処理の内部整合性の確認に用いた。

高いJaccard係数は、機械学習では2特徴が重複・冗長である可能性も示す。同義語や上位・下位カテゴリは両方を自動採用せず、代表特徴を残すか統合する判断材料とする。

### 6．目的変数別の機械学習入力特徴量候補の探索

頻度解析、歯牙障害群と歯牙障害以外群の**平均TF-IDF差**、2-gramおよびJaccard係数の結果を探索的に照合した。採用基準を事前固定して最終選定したものではない。利用できる入力は何を予測するかで変わるため、候補を目的変数別に分ける。

#### 歯牙障害か否かを予測する場合の候補

- 定型項目：学校種、性別、給付年度（西暦換算）、活動場面、通学方法、発生場所等のうち、予測時点ですでに分かる項目
- 受傷機転：転倒、衝突・接触、滑走・滑る、バランスを崩す等
- 原因物・環境：ボール、スポーツ用具、自転車、乗り物、床・地面等
- 活動・場面：練習、試合、野球、登校、下校、通学中等

#### 歯牙障害予測では入力から除外する候補

- 目的変数または受傷結果を直接示す情報：歯牙、前歯、歯、破折、折れる、欠け、脱落等
- 治療後に決まる情報：補綴、歯科受診等
- 目的変数を直接言い換える情報：歯牙障害という分類名そのもの
- 単独では意味が不明確な語：部、本、れる、しまうなど
- 症例の結末を直接表し、予測時点では利用できない情報

目的変数を直接示す語や受傷後の治療情報を入力すると、モデルが事故状況ではなく「答え」を読んでしまうため、情報漏洩に注意する必要がある。

#### 歯牙障害例内で事故類型・受傷機転を分類する場合

歯牙障害か否かの予測とは別の候補表を作る。正解ラベルの作成に使った語を同じモデルの入力に循環利用せず、予測時点で利用可能な場面・行動・原因物の情報を中心にする。前歯や破折等を使えるかどうかは、目的変数と利用場面を決めてから判断する。

## 抄録案

### 演題名

**学校等事故事例検索データベースを用いた歯牙障害事例のテキストマイニング―Jaccard係数による機械学習入力特徴量候補の探索―**

### 【目的】

学校管理下における歯牙障害の予防には、事故発生時の状況を客観的に把握することが重要である。学校等事故事例検索データベースには事故状況が自由記述で収録されているが、その内容を通常の集計だけで十分に利用することは難しい。本研究では、歯牙障害事例の自由記述にテキストマイニングを行い、頻出語、歯牙障害を特徴付ける語および語の組合せを抽出するとともに、Jaccard係数を用いて特徴の重なりを評価し、機械学習に用いる入力特徴量候補を探索することを目的とした。

### 【方法】

日本スポーツ振興センターが提供する学校等事故事例検索データベースから、給付年度を西暦換算して2005～2023年度に相当する歯牙障害事例1,583件を抽出した。事故発生状況の自由記述に対し、PythonおよびJanomeを用いて形態素解析を行い、主に名詞・動詞・形容詞を抽出した。単語の総出現回数と事例出現率を集計し、歯牙障害以外の6,099件と比較した平均TF-IDF差、および解析用語列で隣接する2語の2-gramを求めた。さらに、歯牙障害群内で2特徴の共通事例数を和集合事例数で除したJaccard係数を算出した。複数の探索結果を照合して、目的変数別の入力特徴量候補を整理した。歯牙障害予測では、治療内容、目的変数・受傷結果を直接示す語および単独では意味が不明確な語を除外候補とした。

### 【結果】

頻度解析では、前歯721件（45.5%）、顔面489件（30.9%）、練習462件（29.2%）、歯444件（28.0%）、当たる410件（25.9%）、ボール402件（25.4%）、転倒398件（25.1%）などが多くの事例に出現した。平均TF-IDFの群間差では、前歯、歯、口、顔面、自転車、折れる、転倒、強打、床などが歯牙障害群で高値を示した。解析用語列の2-gramでは、当たる―前歯103件、転倒―顔面92件、顔面―強打87件、自転車―登校70件、転倒―前歯52件、前歯―折れる42件などが認められた。歯牙障害群内のJaccard解析では、自転車―転倒0.329（共通152件）、転倒―顎顔面0.289（242件）、乗り物―転倒0.287（165件）、転倒―歯牙0.233（237件）、スポーツ用具―歯牙0.226（235件）であった。これらは入力候補を考える探索材料となったが、正式な採用や予測寄与を示す結果ではなかった。

### 【考察】

自由記述のテキストマイニングにより、自転車―転倒、転倒―顎顔面、転倒―歯牙、スポーツ用具―歯牙等のペア共起を定量化できた。頻度、平均TF-IDF差、2-gramおよびJaccard係数は候補探索の異なる視点を与えた。一方、複数のペアをつないだ受傷連鎖、歯牙障害群への特異性、予測への寄与は今回のJaccard値からは判断できない。原文語と辞書カテゴリの間では処理上の理由で高値となる場合もある。今後は予測目的を先に定め、歯牙障害予測では前歯・歯牙・破折等を含む結果情報と治療情報を除外し、形態素辞書、TF-IDF、候補選択、しきい値の決定にも使っていないデータで性能を評価する必要がある。
