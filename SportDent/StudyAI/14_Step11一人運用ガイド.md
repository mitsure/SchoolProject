# Step11 一人運用ガイド

## 何を自動化したか

2名の歯科医師を確保しにくい場合に備え、開発用100件について、承認済みコードブックに沿ったAI仮分類と一人研究者用の確認Excelを作成した。

この方式では、AI案があらかじめ各入力欄へ入っている。研究者は原文とAI案を見比べ、必要な箇所だけ修正し、最後に「行確認」を「確認済み」へ変更する。曖昧な事例は「判定不能」とし、接触対象が複数考えられる事例などは確認優先度を高く表示する。

## 開くファイル

`CreateData/Step11_通学中臨床レビュー/InternalReview/SoloAssistedReview/Step11-32_一人研究者確認用_開発用100件.xlsx`

このファイルは原文を含む非公開資料である。共有リポジトリ、投稿資料、外部AIまたは許可されていないクラウドへ送らない。

## 最短の作業手順

1. `AI確認優先度`を「最優先」で絞り込み、赤色の行から確認する。
2. 原文と黄色の判定欄を見比べ、誤りがあればドロップダウンで修正する。
3. コメント必須となる項目では、具体的な対象や部位をコメントへ記録する。
4. その行を確認し終えたら、末尾の`行確認`を`確認済み`にする。
5. 次に「要確認」、最後に「通常」の順で全100件を確認する。
6. 保存後、下記の検査を実行する。

```bash
.venv/bin/python SportDent/file/Step11_通学中臨床レビュー/Step11_SoloAssistedReview.py validate
```

全100件の確認後は、完了検査と確定候補の書き出しを行う。

```bash
.venv/bin/python SportDent/file/Step11_通学中臨床レビュー/Step11_SoloAssistedReview.py validate --require-complete
.venv/bin/python SportDent/file/Step11_通学中臨床レビュー/Step11_SoloAssistedReview.py export-confirmed
```

## 研究上の位置付け

この成果物は「AI仮分類を一人の研究者が全件確認したデータ」であり、2名独立評価ではない。そのため、評価者間一致率やCohenのκは算出できず、調停済みGold Standardとも呼ばない。

研究者による最終確認前でも、`export-ai-provisional`によりCodexの二次整合性検査済み暫定版と内部用集計を作成できる。この暫定版は探索に限って利用し、発表・論文の確定値にはしない。

```bash
.venv/bin/python SportDent/file/Step11_通学中臨床レビュー/Step11_SoloAssistedReview.py export-ai-provisional
```

論文や発表では、必要に応じて次のように記載する。

> 自由記述の構造化には、承認済みコードブックに基づくルールベースの仮分類を用い、研究者1名が原文と全仮分類を照合して修正・確定した。これは2名独立評価ではなく、評価者間一致度は評価していない。

## 590件全体への適用

開発用100件と同じ分類プログラムを、通学中590件の盲検原文全体へ適用した。分類固定後にだけ歯牙障害区分を結合し、結果は`15_Step11通学中590件_AI暫定解析.md`へまとめた。個票と詳細集計は`InternalReview/SoloAssistedReview/Full590/`に保存し、非公開とする。
